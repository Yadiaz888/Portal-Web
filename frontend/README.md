# Frontend

Este directorio contiene todo el código del frontend (React, Vite, Tailwind, etc.).

- Mueve la carpeta **src** y los archivos de configuración de Vite (`vite.config.ts`, `index.html`, `tailwind.config.js`, `tsconfig.*`, `package.json`, `package-lock.json`, etc.) dentro de **frontend**.
- Mantén los scripts de construcción y desarrollo (`npm run dev`, `npm run build`) apuntando a esta carpeta.

> **Nota**: Los archivos todavía se encuentran en la raíz del proyecto; después de moverlos, elimina las copias originales para evitar duplicados.
